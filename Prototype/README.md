# Smart Campus Dashboard Prototype

## 1. Overview

This folder contains photographs of the physical Smart Campus Dashboard prototype developed as part of the mini project.

## 2. Prototype Description

The prototype integrates an ESP32 development board with the sensors and output devices used in the project. The ESP32 processes the available sensor readings and communicates with the monitoring dashboard where configured.
