# Cloud Dashboard

## Description

The cloud dashboard displays the measurements received from the ESP32-based Smart Campus Dashboard system.

## Displayed Parameters

The dashboard may display voltage, current, power, relay status, and other sensor readings according to the implemented configuration.

## Purpose

The dashboard allows users to observe available measurements through a graphical interface and monitor system status remotely when network connectivity is available.
