# Arduino IDE Serial Monitor Output

## Description

The Arduino IDE Serial Monitor displays messages and sensor readings transmitted by the ESP32 during program execution.

## Purpose

The Serial Monitor is used to:
- Observe sensor readings.
- Check whether the ESP32 program is running.
- Inspect relay status messages.
- Identify possible sensor or communication issues.
